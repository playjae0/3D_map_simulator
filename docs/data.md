# 데이터

## 사용 데이터: 국토교통부 GIS건물통합정보

- 공공데이터포털 등록명: 국토교통부_GIS건물통합정보_20260809 (https://www.data.go.kr/data/15083092/fileData.do)
- 제공: 브이월드(V-World)에서 SHP 다운로드, 무료. 다운로드에 로그인 필요
- 이용허락범위: 공공누리 제1유형(출처표시). 출처 표시 시 상업적 이용 가능. 다운로드 파일의 조건은 함께 받은 문서로 재확인
- 내용: 수치지형도 건물 공간정보 + 건축행정시스템(세움터) 건축물대장 속성을 건물 단위로 통합
- 전국 6,656,497건. 구축기관이 지역마다 달라 품질 편차가 있을 수 있음(포털 안내)
- 보유 파일
  - 서울: `AL_D010_11_20261109.zip` (약 140MB)
  - 세종: `AL_D010_36_*.zip` (약 12MB)

## 1단계에서 확인할 항목 (미확인)

1. 필드 목록과 의미. 포털 페이지에 필드 명세가 없다. 칼럼명이 `A0`, `A1`… 형태의 코드일 가능성이 있다(다른 공개 프로젝트에서 같은 출처의 `A13`이 사용승인일로 쓰인 사례). zip 안의 명세서나 V-World 데이터 설명으로 매핑을 확정한다
2. 좌표계: `.prj` 확인. EPSG:5186 등 TM 좌표로 예상
3. 문자 인코딩: `cp949`(EUC-KR)로 예상
4. 높이 필드: 존재 여부, 결측(0·NULL) 비율, 이상값(예: 0.5m 미만, 300m 초과, 층수 대비 비정상)
5. 지상층수 필드: 결측 비율, 높이와의 관계(높이/층수 분포)
6. 주용도 필드: 값 종류와 분포 (외장 패턴 분류에 사용)
7. 형상: 빈 형상, 유효하지 않은 폴리곤, 극소 면적 건물 비율, 중복 건물

## 높이 정제 규칙 (초안, 1단계 결과로 확정)

1. 높이 값이 정상 범위면 사용
2. 높이가 없거나 비정상이고 지상층수가 있으면 `지상층수 × 3m` (계수는 정상 데이터의 높이/층수 분포로 보정)
3. 둘 다 없으면 별도 표시(기본값 사용 여부는 결정 필요)
- 원본 값은 덮어쓰지 않고, 사용한 높이와 출처(원본/층수 대체/기본값)를 칼럼으로 남긴다
