## 높이 정제 규칙 (임시 확정 2026-11-24, 모든 임계값·계수는 서울 확인 후 확정)

h = A16, fl = A26, 면적 = 외곽선 면적(EPSG:5186)

0. 형상: 면적 1m² 미만(placeholder)은 렌더링에서 제외(`h_flag=no_footprint`). 형상이 완전히 같은 중복은 하나만 남긴다(`duplicate`)
1. 원본 사용(`orig`): 2 ≤ h ≤ 600(안전장치)이고
   - fl ≥ 2: 2.0 ≤ h/fl ≤ 8.0
   - fl = 1: h ≤ 20. 공장·창고시설·운동시설·종교시설은 예외로 20m 초과도 원본 사용(`single_story_tall_kept`)
   - fl = 0: 절대 범위만 확인
2. 원본이 없거나 1을 벗어나고 fl > 0 이면 층수 대체(`floors`): `1.9 + 2.9 × fl` (세종 대장 연계 표본의 LAD 적합값, 임시)
3. 높이·층수 모두 쓸 수 없으면 면적 구간별 기본 높이(`area_default`): 20m² 미만 3.5 / 20–50 4.0 / 50–100 4.7 / 100–200 5.9 / 200–500 7.5 / 500 이상 9.5 m (세종 대장 연계 건물의 구간별 높이 중앙값, 임시). 300m² 이상은 `large_default` 표시
- 원본 A16·A26은 덮어쓰지 않고 보존한다. 사용한 높이, 출처(`h_src`), 이상 사유(`h_flag`)를 칼럼으로 남긴다 (칼럼 정의: `schema.md`, 구현: `scripts/refine.py`)
