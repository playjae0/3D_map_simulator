# 실측

## 서울 외곽선 기준 (2026-11-24)

- 데이터: `hanbyul-here/seoul-building-sketch-geoparquet`의 서울 건물 외곽선 (V-World 계열 원본에서 파생, 소형 부속건물 포함)
- 방법: `scripts/measure_density.py`. EPSG:5186 변환, 건물 중심점으로 타일 배정. 삼각형 수는 벽 2e + 지붕 (e−2+2h) 근사(e: 변 수, h: 구멍 수), 바닥면 제외
- 빈 형상 2,643건 제외 후 693,257동

### 전체

| 항목 | 값 |
|---|---|
| 건물 수 | 693,257동 |
| 외곽선 꼭짓점 | 약 470만 개, 건물당 평균 약 6.8개 (고유 꼭짓점 기준, 링을 닫는 끝점 제외) |
| LOD1 삼각형 | 12,684,300개 |
| 완성 메시 저장 시 | 약 430MB(위치+인덱스) ~ 715MB(법선 포함) |
